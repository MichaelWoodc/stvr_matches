FOUND MATCHES — PORTABLE OFFLINE PREVIEW

Open index.html in a modern browser. No installation, Python, web server,
source drives, or access to the original PC is required.

Copy this ENTIRE found_matches folder to the other PC, keeping its subfolders.

Included: 284 listing-pair candidates, 179 Airbnb listings,
1231 supported photo pairs, and 1926 original-resolution images.
Click a listing card to view all matched pairs side by side; click a photo for
its original file. Search, jurisdiction, verification, and evidence filters work
offline. original_preview.html preserves the previous table preview interface.
External Airbnb/Realtor listing links naturally require internet access.

Data scope: all results in the saved live photo-match and ranked-listing CSVs.
The millions of weak/unconfirmed retrieval proposals from all_candidates.html
are not included; its portable link opens the exported found matches instead.
Only matching evidence images are copied, not every photo in each listing.

Photo correspondence is not proof of property identity. Original review notes,
license associations, shared-image warnings and hash/geometric evidence are
preserved. This is a frozen snapshot, not a running matching service.

exports/ contains portable CSVs and source audit/context records.
manifest.json maps every copied image back to its original source path and size.
Original photos were copied without recompression and checked by byte size.
